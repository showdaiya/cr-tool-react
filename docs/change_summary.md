# 変更内容サマリ

## 対象ドキュメント
- `docs/basic_design.md`
- `docs/detailed_design.md`
- `docs/function_overview.md`

## 主な変更点
1. **基本設計書の機能別整理**
   - セクションを「防衛カード管理」「攻撃カードスロット管理」「攻撃カード選択モーダル」「ダメージ計算・結果表示」の 4 機能に再構成。
   - 各機能について UI 構成・入出力データ表・処理フロー・バリデーションを明文化。
   - カード辞書の正規化ルールや DamageSummary の取り扱いなど、共有データモデルを冒頭に定義。

2. **詳細設計書の更新**
   - コンポーネント構成図、Context / Reducer の責務分離、カスタムフックの入出力を明記。
   - ダメージ計算ロジックを擬似コードで提示し、単発ダメージ算出・合計ダメージ更新の流れを追記。
   - 入力検証・エラーハンドリングの条件と UI フィードバックを各機能に紐づけて整理。

3. **機能一覧の拡張**
   - 現行と再実装後の差分を明示し、各機能の完了条件・開発メモを補足。
   - 画面横断の共通要件（レスポンシブ、アクセシビリティ）を抜け漏れなく列挙。

## 補足
- すべてのドキュメントは Clash Royale ダメージツールの再実装を前提に整備。
- 今後のレビューで追加要望が出た場合は、機能ごとに該当セクションへ追記していく。
