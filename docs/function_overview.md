# 機能一覧（ドラフト）

本書は再構築対象となる Clash Royale ダメージ計算ツールの「提供機能」にフォーカスした一覧です。画面仕様や技術選定などの詳細は `basic_design.md` および `detailed_design.md` を参照してください。

## 1. 基本機能

### 1.1 防衛カード関連
- 防衛カードの初期表示（デフォルトカードを設定）。
- 防衛カード選択モーダルの表示。
- 防衛カードの選択変更と状態保持。
- 防衛カード情報（画像、HP、被ダメージ、残り HP）のリアルタイム表示。

### 1.2 攻撃カード関連
- 攻撃カードスロットの追加。
- 各スロットでのカード種別（Troop / Spell）選択。
- 攻撃回数の入力（直接入力・増減ボタン）。
- 攻撃カード情報（画像、単発ダメージ、攻撃回数、総ダメージ）の表示。
- 攻撃カードモーダルの開閉（選択・編集）。

### 1.3 ダメージ計算
- 各攻撃カードの総ダメージ計算。
- 攻撃カード全体の被ダメージ合計算出。
- 防衛カード残り HP の算出（0 未満は 0 として表示）。

### 1.4 UI 更新
- 状態変更に応じた各種数値・表示のリアルタイム更新。
- モーダルのフォーカストラップとキーボード操作への対応。

## 2. 追加検討中の機能
- 攻撃カードスロットの削除。
- 攻撃カードの並び替え。
- シナリオ（攻防セット）の保存・読み込み。
- カードデータの外部 API 化。
- 多言語対応（日本語 / 英語切り替え）。

## 3. 非機能的な補足
- ローカル JSON をデータソースとしたクライアントサイドのみの構成。
- レスポンシブデザイン（PC / モバイル対応）。
- Chakra UI をベースとしたスタイル統一とテーマ管理。
